1. **docs/Part-II-Submission.pdf** - the overview, shell summary, requirements, and wireframes.

## Before submitting

- Read the PDF and replace wording if needed to reflect your intended project.
- Confirm whether the instructor accepts .NET 8; the reference tutorial uses the older .NET Core 3.1.
- If the assignment portal asks for your name, course number, section, or date, enter those in its submission fields.
- Open the solution and run the http profile once on your computer.
- Confirm the instructor can open the repository link. A private repository requires instructor access.
- Check any course-specific instructions about acknowledging AI assistance.

## Demonstration sequence

1. Open the home page and explain the problem the system addresses.
2. Open Services to show data passed from a controller to a Razor view.
3. Open Request form and submit it empty to display validation errors.
4. Enter fictional data and test validation again. Point out that this shell does not save or send requests.
5. Open Dashboard preview and explain the fictional records and status totals.
6. Open Project plan to distinguish completed shell features from later database, account, role, and API work.

## Questions you should be able to answer

- What does each part of MVC do in this project?
- Where are form validation rules defined?
- What happens when a visitor submits the form today?
- Which database entities and user roles are planned?
- Why is weather information relevant to paving work?
